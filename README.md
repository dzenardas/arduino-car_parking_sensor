# Car Parking Sensor
This project simulates a car parking sensor using Arduino Uno R3 and other components in Tinkercad (see documentation.pdf for the full parts list and wiring). Ultrasonic sensor measures the distance to an obstacle. The closer the obstacle gets, the faster the buzzer beeps. LED bulbs changes from green to red depending how close object is and distance is shown on the LCD.

## Features
- Measures distance with an ultrasonic sensor
- Green, yellow and red LEDs show how close the object is
- Buzzer (Piezo) beeps faster as the object gets closer
- LCD shows the distance in cm

## How to use:
1. Open this project in Tinkercad;
2. Start the simulation;
3. Click the ultrasonic sensor and move the object closer or further away;
4. Watch the LEDs, listen to the buzzer and see the distance shown on the LCD.
